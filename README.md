# پنل v2ray (3x-ui) — دیپلوی خودکار

## روش ۱: روی سرور (Ubuntu/Debian)
unzip v2ray-panel.zip && cd v2ray-panel
sudo bash install.sh

## روش ۲: روی پلتفرم (lucity.cloud)
فایل‌ها را آپلود کنید؛ Dockerfile و docker-compose.yml آماده‌اند.
پورت پنل: 2053 — پورت اینباند: 443

## بعد از نصب
- ورود: admin / admin ← فوراً عوض کنید
- در Settings مسیر (path) و پورت پنل را تغییر دهید
- بکاپ: پوشه db/
